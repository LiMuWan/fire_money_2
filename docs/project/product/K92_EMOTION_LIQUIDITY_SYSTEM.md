# K92 情绪流动性研究系统

## 定位

K92 情绪流动性系统是从“92 科比式短线经验”抽象出来的研究影子系统，不是默认交易主线。它的任务是解释每天的局部小牛市到底属于哪一种资金状态：

- 龙头进攻日：情绪强、换手龙质量强、主线候选密集。
- 低位补涨日：情绪中等，高位龙头不清晰，但低位补涨有资金承接。
- 题材切换观察日：旧龙头不够强，新方向有 ready 候选，只观察不抢。
- 退潮空仓日：情绪弱、候选少或风险候选多，空仓是策略。

## 不进入默认模拟盘的原因

当前默认赚钱闭环仍然只经营 `board-shadow-system` 和 `cash`。K92 系统在没有完成 2020-2026 point-in-time 回测、分年收益、月度收益和回撤验证前，不能写入模拟盘买入，也不能发飞书买卖提示。

它现在只提供：

- 市场情绪状态判断。
- 龙头进攻、低位补涨、题材切换、风险-only 分组。
- 候选的名称（代码）、换手质量、主线强度、60 日位置、市值。
- 下一步研究动作。

## 研究规则

- 只研究主板 10cm、非 ST、非新股、50-800 亿市值。
- 高位只做龙头分歧转一致，不做中位跟风。
- 龙头不清晰时只观察低位补涨或题材切换。
- 弱市、退潮、风险候选多于 ready 候选时，默认空仓。
- 任何候选进入真实模拟盘前，必须证明分年收益、月度稳定性和最大回撤不拖累主线。

## 下一阶段

1. 基于现有 daily cache 补 2020-2026 逐日回测。
2. 输出年度收益、月度收益、胜率、最大回撤和最弱年份。
3. 对比当前主线，如果不能提升收益质量或降低回撤，就保持研究封存。
4. 只有通过验证后，才考虑把 K92 的“状态机”并入默认主线守门，而不是单独扩大交易入口。

## v1 回测结果

命令：

```powershell
python -B -m client.desktop.firemoney_client.one_to_two_cli k92-backtest --start-date 2020-01-01 --end-date 2026-05-05 --brief
```

当前缓存覆盖 `2019-05-27 -> 2026-04-30`。K92 v1 在 `2020-01-01 -> 2026-05-05` 的影子回测状态为 `ready`：

- 样本：378 笔。
- 胜率：62.70%。
- 8% 仓位复合收益：148.54%。
- 最大回撤：-2.62%。
- 年度：2020-2026 七个有样本年份全部正收益。
- 月度：68/76 个正收益月份，月度正收益占比 89.47%。
- 最差月份：2025-01，-0.87%。
- 最长连续亏损月：2。

结论：K92 v1 可以进入下一阶段“影子观察 + 与主线对照”，但不能承诺每月都赚钱，也不能直接替代 `board-shadow-system` 写入模拟盘。下一步只允许研究它作为主线守门增强项：当 K92 状态为退潮空仓日时减少交易，当 K92 状态为龙头进攻日时提高候选置信，但不新增第二条默认开仓线。
