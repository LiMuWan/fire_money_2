# FireMoney Zanger 式强势突破技能蒸馏与产品改进建议

## 结论先行

本次按 Nuwa 的方法，不复制人物口号，只抽取可验证的认知操作系统。公开资料里最接近“个人股票交易收益率极端样本”的是 Dan Zanger：其官网和第三方复核文章都提到，他在 1998-2000 科技股泡沫中用高杠杆和高成长互联网股票取得过极端收益记录。

这类收益不可复制、不可承诺，也不应成为 FireMoney 的目标口号。FireMoney 可以复制的是交易框架：

```text
强市场 -> 强板块 -> 强股票 -> 强结构突破 -> 强成交确认 -> 失败快速退出 -> 只复盘真实样本
```

对应到产品，下一阶段不该继续扩展界面和战法，而应该把当前主线升级成“主线强势突破经营系统”：只有市场、板块、结构、量能、风险收益同时满足时才买；否则空仓。

### 边界

- 公开资料不等于完整交易账本，不能还原全部仓位、杠杆、滑点和卖点。
- Zanger 的极端收益发生在特殊牛市阶段，不能外推到普通市场。
- A 股有 T+1、涨跌停、集合竞价、封单排队和流动性约束，不能直接照搬美股突破交易。
- 本文只提炼可工程化的交易技能，不承诺稳定盈利。

## Nuwa 式蒸馏结果

### 心智模型 1：先判断市场是否允许进攻

强势突破交易不是每天都做。最重要的前置条件不是“今天有没有股票涨停”，而是：

- 指数和赚钱效应是否支持进攻。
- 领涨板块是否清晰。
- 资金是否愿意追高。
- 强势股失败后是否快速负反馈。

FireMoney 对应改进：

- 保留 `cash` 作为正式策略，不把空仓视为失败。
- 现有市场温度还不够，应增加市场宽度、主线集中度、涨停溢价、炸板亏钱效应等状态字段。
- 在弱市里，即使单票形态好，也应降低仓位或直接不买。

### 心智模型 2：只买最强结构，不买普通上涨

Zanger 式交易强调图形、趋势线、平台、旗形、三角形、杯柄等结构，但真正核心不是图形名称，而是“资金在收敛后重新选择方向”。

FireMoney 对应改进：

- 当前候选已有主线、量能、均线和 50-800 亿市值过滤，但还缺“结构突破评分”。
- 应新增结构字段：
  - `base_tightness_score`：平台/整理区间是否足够紧。
  - `breakout_distance_pct`：买点距离结构突破线是否过远。
  - `relative_strength_score`：相对大盘和板块是否持续领先。
  - `volume_surge_score`：突破日成交是否显著放大。
  - `overhead_supply_score`：左侧压力是否足够干净。

### 心智模型 3：成交量是突破可信度，不是装饰指标

公开资料多次强调 Zanger 对价格和成交量的重视。突破如果没有成交量，容易是假突破；放量太极端也可能是高潮或一致性拥挤。

FireMoney 对应改进：

- 现有 `volume_ratio_20d` 不应只是最低门槛，应变成分段质量：
  - 低于 1.5：不确认突破。
  - 1.5 到 2.5：正常确认。
  - 2.5 到 4.0：强确认但检查是否高潮。
  - 高于 4.0：进入拥挤/高潮风险分支。
- 盘中值守应尽量加入“实时成交节奏”近似字段，先用分钟线或集合竞价金额比例替代 Tick。

### 心智模型 4：失败的突破必须立刻降级

突破交易的优势来自少数大胜覆盖多次小错。失败后不快速处理，就会把系统从趋势交易变成被套补仓。

FireMoney 对应改进：

- A 股 T+1 不能日内卖出，所以要做两层处理：
  - 买入当日：标记 `failed_breakout_warning`，禁止加仓，飞书只提示风险。
  - T+1：若跌回突破线或结构支撑下方，优先纪律退出。
- 当前止损和时间退出已有基础，但应把“跌回突破点”作为比固定百分比更靠前的退出原因。

### 心智模型 5：仓位应按风险定，不按心情或固定比例定

Zanger 的极端收益部分来自集中和杠杆，这不适合当前 FireMoney 默认产品。我们要复制的是“在确定性更高时让收益奔跑”，不是复制高杠杆。

FireMoney 对应改进：

- 当前默认单票仓位 `8%` 简洁，但不够精细。
- 应升级为风险预算仓位：

```text
position_pct = min(max_position_pct, account_risk_budget_pct / planned_stop_risk_pct)
```

- 如果止损距离更宽，仓位自动变小；如果止损距离更窄且结构更强，才允许接近上限。

### 心智模型 6：只在领涨板块里找股票

个人交易者很难靠全市场乱扫稳定胜出。强势股通常来自强主题、强行业、强赚钱效应。

FireMoney 对应改进：

- 候选卡片必须显示股票名、代码、题材/行业、主线强度。
- 策略层应增加 `industry_leadership_score`：
  - 同板块涨停数量。
  - 同板块首板/二板梯队。
  - 板块内候选平均成交额和封板质量。
  - 龙头是否清晰。

## 对 FireMoney 当前产品的判断

### 做得对的地方

- 产品已经收缩到主线和现金，方向是对的。
- 50-800 亿市值过滤符合“可成交、有弹性、非微盘博弈”的思路。
- 模拟盘已有买入、卖出、收益、回撤、SQLite 记录和飞书低噪声边界。
- 当前页面已经开始从“大长屏研究报告”转成单屏决策台。
- 主升持有和普通锁盈已分层，说明卖点开始从“赚一点就跑”转向“强者多拿，弱者快卖”。

### 仍然不够像强交易系统的地方

- 买点更多是候选质量和开盘确认，还没有显式识别“结构突破线”。
- 市场状态还偏产品语言，缺少更硬的赚钱效应/亏钱效应指标。
- 仓位仍偏固定比例，没有完全按实际止损距离和单笔风险定。
- 卖点还没把“跌回突破点/平台上沿”放到足够高优先级。
- UI 右侧证据可以折叠，但核心卡还应该显示“为什么这只票是强突破”，而不是只显示策略结论。
- 回测需要继续从收益率展示升级到 R 倍数、失败突破率、样本分布和弱市分段。

## 优先级改进清单

### P0：先补结构突破评分

新增 `breakout_structure_score`，进入模拟买入前必须通过：

- 均线多头。
- 近 N 日形成平台或收敛结构。
- 当日突破关键高点或平台上沿。
- 距离突破线不超过配置上限。
- 成交量超过 20 日均量的最低确认线。
- 左侧压力不密集。

验收标准：

- `paper-decision --brief` 明确显示结构评分和突破线。
- 2020-2026 回测新增“有结构评分 vs 无结构评分”对照。
- 若收益下降但最大回撤显著下降，可以进入观察；若弱年份变差，不升级默认。

### P1：把仓位从固定 8% 改成风险预算

保留 `max_position_pct=8%` 上限，但默认按止损距离计算：

- 强结构、窄止损：可接近 8%。
- 普通结构、宽止损：自动降到 4%-6%。
- 市场状态不佳：即使单票强，也不超过降级仓位。

验收标准：

- 每张指挥单显示“计划亏损占账户比例”。
- 回测展示固定仓位与风险预算仓位对比。

### P2：新增失败突破纪律

新增退出原因：

- `failed_breakout_exit`
- `breakout_line_lost`

触发逻辑：

- T+1 可卖时，若收盘/盘中近似跌回突破线下方，优先退出。
- 若主线继续强但个股跌回突破线，只保留一次容错，不允许变成长期持仓。

验收标准：

- 闭环样本里能统计失败突破次数、平均损失和是否被快速截断。

### P3：板块领导力进入硬门槛

新增 `industry_leadership_score`，弱板块中的单票强势只观察，不买。

验收标准：

- 指挥单显示“板块强度：强/中/弱”。
- 弱板块候选不得仅凭个股评分进入模拟买入。

### P4：UI 只展示交易员需要的 5 个答案

首屏只回答：

```text
今天做不做？
买哪只？
为什么它强？
错了在哪里走？
这笔最大能亏多少，第一目标能赚多少？
```

右侧证据折叠保留，但核心卡要增加：

- 股票名（代码）。
- 所属主线/行业。
- 结构类型。
- 突破线。
- 放量确认。
- 风险收益比。

## 下一轮建议实施方案

### 服务端

- 新增 `breakout_structure_service.py` 或 domain policy。
- 在候选生成后附加结构评分，不让客户端计算交易规则。
- `paper_instruction_builder.py` 展示突破线、结构类型和失败突破取消条件。
- `paper_exit_policy.py` 增加 T+1 失败突破退出。
- 配置文件增加结构评分阈值和成交量分段阈值。

### 回测

- 新增结构评分开关对照。
- 输出年度收益、月度收益、最大回撤、平均 R、失败突破率。
- 必须用 2020-2026 全区间，并单列 2021 弱市、2024-2026 验证段。

### UI/通知

- 只在早评、真实模拟买入、真实模拟卖出、晚评中展示新增结构证据。
- 候选和通知统一使用“股票名（代码）”。
- 用颜色区分：
  - 绿色：允许买/持有。
  - 橙色：观察/降仓。
  - 红色：取消/卖出/空仓。

## 一句话原则

FireMoney 不应该追求每天都有提示，而应该追求只有真正像样的强势突破才提示；一旦提示，就必须能说清楚结构、板块、量能、风险和卖点。
