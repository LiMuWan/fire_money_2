# 运行与验证 - Run And Verify

## 本地自测

```powershell
python -B -m unittest discover -s tests -v
```

只测关键边界：

```powershell
python -B -m unittest tests.test_application_boundaries -v
python -B -m unittest tests.test_strategy_decision_service -v
python -B -m unittest tests.test_paper_entry_policy tests.test_paper_exit_policy -v
python -B -m unittest tests.test_notification_orchestrator tests.test_one_to_two_notification_text -v
python -B -m unittest tests.test_linux_deployment_scripts -v
```

## 腾讯云验收

```bash
cd /opt/firemoney
bash scripts/linux/check_firemoney_server.sh
```

必须确认：

- `firemoney-preview.service` 运行中。
- `core_workflow.html` 返回 FireMoney 页面。
- `firemoney-beta-watch.service` 不重复。
- 飞书配置不进入 Git。
- 非交易日不发送早评/晚评。

## Git 纯洁性检查

```powershell
git status --short
git ls-files client/desktop/preview
```

`client/desktop/preview/` 只应该保留说明文件，不应该提交生成的 HTML、截图、JSON 或 SQLite。
