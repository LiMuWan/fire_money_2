# 快速开始 - Quick Start

## 环境要求

- Python 3.12+
- Windows PowerShell 或 Ubuntu Bash
- 可选：飞书群机器人或飞书应用机器人

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

---

## 先用样例数据跑通

样例数据不会访问真实行情，也不会产生真实模拟盘账本：

```powershell
python -B -m client.desktop.firemoney_client.one_to_two_cli strategy-decision --sample-data --brief
python -B -m client.desktop.firemoney_client.one_to_two_cli paper-decision --sample-data --brief
python -B -m client.desktop.firemoney_client.one_to_two_cli doctor --sample-data --brief
```

这三条命令分别回答：

- 今天走主线还是空仓？
- 如果可以买，模拟盘买什么、怎么买、怎么卖？
- 当前运行环境是否健康？

## 生成预览页

```powershell
python -B -m client.desktop.firemoney_client.preview
```

启动本地预览服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_core_workflow_preview.ps1
```

浏览器访问：

```text
http://127.0.0.1:8765/core_workflow.html
```

预览文件位于 `client/desktop/preview/`，属于生成物，不提交到 Git。

## 配置飞书

推荐把本地密钥放到被忽略的 `.firemoney/feishu.env`：

```text
FEISHU_ENABLED=true
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/...
FEISHU_WEBHOOK_SECRET=
```

或者使用飞书应用机器人：

```text
FEISHU_ENABLED=true
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx
FEISHU_RECEIVE_ID=oc_xxx
FEISHU_RECEIVE_ID_TYPE=chat_id
```

测试飞书：

```powershell
python -B -m client.desktop.firemoney_client.one_to_two_cli feishu-test
```

`feishu-test` 只验证联通，不代表交易信号。

## 可选：接入 QMT

QMT/MiniQMT 是本地 Windows 券商终端网关，不放到腾讯云上跑。先在本机启动并登录 MiniQMT，再配置：

```powershell
$env:FIREMONEY_QMT_PATH="C:\...\userdata_mini"
$env:FIREMONEY_QMT_ACCOUNT_ID="你的股票账号"
python -B -m client.desktop.firemoney_client.one_to_two_cli qmt-check --brief
python -B -m client.desktop.firemoney_client.one_to_two_cli qmt-plan --brief
```

默认只输出 dry-run 拟委托。实盘提交必须同时传 `--qmt-submit` 并设置 `FIREMONEY_QMT_ALLOW_LIVE=true`。

## 真实行情入口

真实行情默认通过 AkShare 获取。行情源不可用时，系统会阻止模拟买入：

```powershell
python -B -m client.desktop.firemoney_client.one_to_two_cli beta-check --market-data-timeout-seconds 20
python -B -m client.desktop.firemoney_client.one_to_two_cli beta-start --loop --interval-seconds 60 --market-data-timeout-seconds 20
```

建议上线前先跑：

```powershell
python -B -m unittest discover -s tests -v
```
