# 3-3. 部署与值守模块 - RuntimeDeployment

## 模块概述

部署与值守模块负责让 FireMoney 稳定运行：本地可以调试，腾讯云可以常驻，且同一时间只保留一个预览服务和一个值守循环。

---

## 核心优势

1. **单实例**
   Windows 使用进程检查和互斥思路，Linux 使用 `flock`。

2. **可自启**
   腾讯云通过 systemd 托管 `firemoney-preview` 和 `firemoney-beta-watch`。

3. **可诊断**
   健康检查覆盖 HTTP、端口、服务状态、调度覆盖和核心命令。

4. **非交易日不扰民**
   非交易日不发送早评、晚评，也不生成模拟买入。

---

## 核心文件

| 文件 | 职责 |
|---|---|
| `scripts/start_core_workflow_preview.ps1` | Windows 本地预览服务 |
| `scripts/check_firemoney_runtime.ps1` | Windows 本地运行诊断 |
| `scripts/deploy_tencent_ubuntu_one_click.ps1` | Windows 一键上传部署 |
| `scripts/linux/install_firemoney_systemd.sh` | Ubuntu 安装 systemd 服务 |
| `scripts/linux/start_firemoney_preview.sh` | Linux 预览服务启动脚本 |
| `scripts/linux/start_firemoney_beta_watch.sh` | Linux 值守循环启动脚本 |
| `scripts/linux/check_firemoney_server.sh` | Linux 服务器验收脚本 |

---

## Linux 服务

```text
firemoney-preview.service
  -> 预览页 HTTP 服务，默认 8765

firemoney-beta-watch.service
  -> 模拟盘值守循环
  -> 只在 beta-check/doctor 通过后建议启动
```

两个服务统一读取：

```text
/etc/firemoney/firemoney.env
```

运行数据统一写入：

```text
/opt/firemoney/.firemoney/
```

---

## 推荐上线顺序

1. 本地运行样例数据。
2. 本地跑完整单测。
3. 腾讯云部署预览服务。
4. 配置飞书密钥。
5. 跑 `doctor`、`beta-check`、`feishu-test`。
6. 确认飞书收到测试消息。
7. 启动 `firemoney-beta-watch`。
8. 运行服务器健康检查。
