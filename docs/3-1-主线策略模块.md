# 3-1. 主线策略模块 - MainlineFirstBoardStrategy

## 模块概述

主线策略模块负责回答“今天有没有值得模拟盘出手的主板 10cm 主线首板候选”。它只使用当时可见的数据做判断，避免未来函数。

---

## 核心优势

1. **主线收缩**
   默认只经营主线首板和现金空仓，不让研究线干扰每日决策。

2. **小账户友好**
   默认本金 1 万，必须满足 A 股一手交易约束，买不起就空仓。

3. **风险优先**
   买入前先给止损、第一目标、仓位上限和取消条件。

4. **证据升级**
   策略升级必须经过回测、弱年份、验证段和最大回撤检查。

---

## 当前默认边界

| 维度 | 当前规则 |
|---|---|
| 市场 | A 股主板 10cm |
| 市值 | 50-800 亿 |
| 排除 | ST、退市、新股、创业板、科创板、北交所 |
| 账户 | 默认 1 万模拟本金 |
| 交易频率 | 每天最多 1 笔模拟买入 |
| 买点 | 主线首板候选，次日开盘确认 |
| 风控 | 结构止损、收益守门、主升保护、时间纪律 |
| 默认路由 | 主线或空仓 |

---

## 核心流程

```text
行情归一化
-> 主板 10cm 候选筛选
-> 市值 / ST / 板块硬拦截
-> 封板质量、换手质量、主线持续性评分
-> strategy-decision 选择主线或空仓
-> paper-decision 生成只读指挥单
-> watch/open 满足条件才写入模拟买入
-> watch/risk 执行风险预警和 T+1 卖出
```

---

## 买入纪律

- 行情不可用时禁止买入。
- 非交易日不生成买入。
- 已持仓或当天已交易满额时不买入。
- 开盘确认必须满足红盘、不过高、封板资金和主线质量要求。
- 收益守门未达标时只允许小仓验证或直接空仓。

---

## 卖出纪律

- 跌破止损先做风险预警，T+1 仍不修复才模拟卖出。
- 普通信号达到正收益锁盈线后优先保护收益。
- 强信号进入主升持有模式后，使用分段回撤保护。
- 持仓超过纪律时间且没有走强，执行时间纪律退出。
