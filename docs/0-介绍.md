# 介绍 - FireMoney Introduction

## FireMoney 是什么？

FireMoney 是一个 A 股主板 10cm 主线首板研究与模拟盘值守项目。它把候选筛选、买卖指挥单、模拟盘账本、飞书通知、尾盘复盘和回测证据放在同一条闭环里，方便持续验证一套交易纪律是否真的值得经营。

当前默认产品面只保留：

```text
主线首板
现金空仓
```

研究能力可以存在于代码或历史资料中，但不会默认出现在每日经营入口。

---

## 核心能力

### 主线候选

- 聚焦主板 10cm。
- 默认排除 ST、退市、新股、创业板、科创板、北交所。
- 默认关注 50-800 亿市值带。
- 同时看市场温度、封板质量、换手质量、主线持续性和位置结构。

### 模拟盘纪律

- 默认 1 万模拟本金。
- 小账户优先保证一手可买和仓位上限。
- 每天最多一笔模拟买入。
- 买入必须给出入场价、止损、第一目标、取消条件和风险预算。
- 卖出按止损、锁盈、主升保护、时间纪律等规则执行。

### 低噪音飞书

只发送四类消息：

- 早评。
- 真实模拟买入。
- 真实模拟卖出。
- 晚评。

普通扫描、候选变化、医生检查和本地指挥单不主动推送，避免把用户淹没在噪音里。

### 证据优先

策略升级必须回到历史区间做 point-in-time 验证，不能用未来走势倒推买点。评估时不只看总收益，也要看弱年份、最大回撤、月度收益、样本数和收益/回撤质量。

## 当前阶段

```text
Phase 01: 主线收缩
  -> 默认只经营主线首板或空仓
  -> 研究线退出默认产品面

Phase 02: 模拟盘稳定
  -> 买点、卖点、仓位和飞书通知闭环
  -> JSON + SQLite 记录可复盘账本

Phase 03: 部署值守
  -> Windows 本地可跑
  -> 腾讯云 Ubuntu systemd 常驻
  -> 单实例、健康检查、非交易日不扰民
```

---

## 明确不做

- 不连接真实券商账户。
- 不自动实盘下单。
- 不保证每笔交易赚钱。
- 不把样例数据当真实收益。
- 不把飞书联通测试当交易信号。

---

## 风险说明

FireMoney 是研究和模拟盘工具，不构成投资建议。A 股短线交易波动大，任何实盘操作都需要独立判断并承担风险。
