## 文档红线

1. 只写当前代码真实支持的能力，不把计划写成已完成。
2. 运行态、截图、账本、SQLite、密钥和本地模板不进入公开文档资产。
3. 默认用户路径只描述主线首板和空仓，不把研究线包装成可用策略。
4. 涉及收益必须同时说明样本、回撤和验证边界。
5. 文档改动要能帮助新用户在 10 分钟内跑通样例命令。
