# FireMoney 共享契约

共享层用于约束客户端和服务端之间的公共语言，避免两边各自发明字段和状态。

---

## 模块定位

共享层负责：

- 定义报告 DTO。
- 定义状态枚举。
- 定义跨端字段含义。
- 保持 CLI、预览页和未来 HTTP/RPC 接口的一致性。

共享层不负责：

- 读写本地文件。
- 访问 AkShare。
- 发送飞书。
- 执行交易规则。

---

## 目录结构

```text
contracts/
  trading.py          主线策略、模拟盘、通知和复盘 DTO
  paper_database.py   模拟盘数据库报告 DTO

docs/
  CONTRACTS_V1.md     契约说明
```

---

## 边界红线

1. 新跨端字段先进入 `shared/contracts`。
2. 客户端不能根据缺字段自行推断交易结论。
3. 服务端返回字段必须能支撑 UI 回答：状态、风险、下一步、证据。
