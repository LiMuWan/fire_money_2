# FireMoney Server

服务器/业务层负责一进二战法的可信规则、状态和外部系统适配。首版可以是本地进程内服务，但边界按服务端方式设计。

## 职责

- 读取一进二策略配置。
- 通过 `MarketDataProvider` 获取并归一化行情。
- 对昨日首板样本进行评分、拦截和风险提示。
- 维护事件驱动模拟盘账本。
- 生成早盘报告、盘中事件、尾盘测评和稳定性报告。
- 发送或准备飞书通知结果，通知失败不影响策略运行。

## 非职责

- 不构建 UI。
- 不连接真实账户，不自动实盘下单。
- 不把 AkShare 字段名、飞书密钥或本地文件结构暴露给策略和客户端。
- 不保留旧交易执行入口、通用机会池或多战法链路。

## 分层

```text
Application/     一进二用例编排
Domain/          评分、拦截、位置结构、止损纪律
Infrastructure/  行情源、飞书、本地模拟盘、配置
Contracts/       对外 DTO 和状态枚举
Tests/           一进二业务和契约测试
```
