# FireMoney Server

服务器/业务层负责可信规则、状态和外部系统适配。首版可以是本地服务或进程内业务层，但边界必须按服务端思路设计。

## 职责

- 策略扫描、推荐、评分和解释。
- 风控审查、异常阻断、仓位约束。
- 账户、资金、持仓、委托、回执状态。
- 东方财富 CSV、GM SDK、数据源和消息源适配。
- 执行日志、失败原因、复盘报告和次日计划。

## 非职责

- 不直接构建 UI。
- 不弹窗、不控制页面跳转。
- 不依赖客户端控件状态。
- 不把外部 SDK 细节泄露给业务服务。

## 建议分层

```text
Application/     用例编排、工作流、权限和校验
Domain/          策略、风控、执行、复盘规则
Infrastructure/  存储、文件、SDK、数据源、消息源
Contracts/       对外 DTO、错误码、状态枚举
Tests/           服务端业务和契约测试
```
